# Screenshot notes

These are browser captures of the extension running on Flarum 2.0.2, taken with Chromium through Playwright on 2026-10-21. They show the actual forum and administration components, with English and Simplified Chinese language resources.

The homepage layout, branding, discussions, members and statistics use temporary demonstration data supplied to the browser. They do not describe a real community or its membership. No forum settings, posts, accounts or language preferences were saved to create these examples. The admin page uses a read-only server-rendered document and an in-memory session; no saved login was created or used. No screenshot is an AI-generated mockup.

The example includes seven native widgets: a notice, a banner, discussions, search, statistics, users and links. Its palette is an example, not a required theme. Other extensions visible in the administration sidebar are installed on the capture forum and are not dependencies of DIY Homepage. The public default layout remains unchanged.

| File pattern | View | Capture size |

`en` denotes English; `zh-CN` denotes Simplified Chinese. The mobile images use a browser viewport, not a photograph of a physical phone. The screenshots demonstrate layout and configuration; they do not replace device or accessibility testing.
