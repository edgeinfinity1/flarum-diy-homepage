# Design notes / 后续候选

Feedback: https://discuss.flarum.org/d/40135/26 (2026-10-25).

- **Future candidate, not scheduled:** multiple configurable pages, similar to FoF Pages. Requires a separate design for routes, page permissions, defaults and compatibility. No implementation in this change.
- **暂记候选、暂无计划：** 类似 FoF Pages 的多个可配置页面。路由、权限、默认入口与兼容性需另行设计，本轮不实现。
- **Not planned:** a moderator-managed promoted discussion collection exposed in the IndexPage view selector. Editorial promotion and discussion-list views are outside this homepage composition extension's intended scope.
- **不采纳：** 版主推送指定讨论到集合、并将其加入 IndexPage 视图下拉菜单；这属于内容推荐工作流与讨论列表视图，偏离本插件设计目的。
